# 教程章节：让微信秒回——快速通道与免费快模型

## 先说结论

微信桥刚装好的时候，一条消息要等 97 秒才有回复（实测）。不是微信慢，是回消息的 Agent「启动太重」：每来一条消息都要冷启动一个完整会话、加载全部上下文，简单问题和复杂任务挤同一条队。

解法是给桥加一条**快速通道**：简单问题交给一个免费的小模型秒答，复杂任务才转给主 Agent 慢慢办。改造后实测：新问题约 3.5 秒、重复问题约 2 秒、复杂任务 1 秒内先收到回执。这一章你不需要写代码——把配套的《给学员的 Agent-安装指令》发给你的 AI 助手，它会自己部署，并主动向你要一样东西：一个免费模型的 API Key。下面讲你唯一要动手的部分：注册。

## 快速通道的原理（三句话版）

1. 微信消息进来，快速通道在 0.3 秒内先把消息「认领」下来（全桥只有一个认领者，杜绝重复回复）。
2. 能直接答的常识问答，小模型当场答完；要查资料、动工具、记事情的，转给主 Agent，同时先秒发一句「收到，这件事我来办，稍等一下。」
3. 小模型的连接保持常开、重复问题走缓存，所以越聊越快。

## 五家免费快模型，任选一家

全部国内直连、注册免费、接口互通（核实日期：2026-11-04；免费政策变动较快，注册时以平台控制台显示为准）。

### 1. 智谱 BigModel（推荐，永久免费）

- 免费点：`glm-4.7-flash` 是官方免费模型，长期 0 元；新用户另赠约 2000 万 tokens 体验额度。
- 注册步骤：打开 open.bigmodel.cn → 手机号注册 → 完成实名认证 → 进控制台点「API 密钥」→ 创建 → 复制 Key。
- 注意：免费的 Flash 型号偶尔会换代（旧型号下线会自动转到新型号），哪天突然调不通，先去控制台看当前免费名单。

### 2. 硅基流动 SiliconFlow（一个 Key 能换很多模型）

- 免费点：注册送约 14 元代金券，实名认证再领约 16 元；9B 以下的开源小模型永久免费调用。
- 注册步骤：打开 cloud.siliconflow.cn → 手机号注册 → 实名认证 → 左侧「API 密钥」→ 新建 → 复制 Key。

### 3. 阿里云百炼（免费额度大方，限时 90 天）

- 免费点：新开通用户每个模型自动发 100 万 tokens，90 天有效；快模型用 `qwen-flash`。
- 注册步骤：阿里云账号登录 bailian.console.aliyun.com → 开通百炼（地域一定选华北2·北京，其他地域没有免费额度）→ 创建 API Key → 复制。
- 防扣费：控制台里打开「免费额度用完即停」，额度耗尽自动停，不会偷偷扣钱。

### 4. 火山方舟·豆包（备选）

- 免费点：每个模型 50 万 tokens 免费额度，有「安心体验模式」只消耗免费额度。
- 注册步骤：火山引擎注册并实名 → console.volcengine.com/ark 开通方舟 → 创建 API Key → 复制。

### 5. DeepSeek 官方（不算免费，但便宜到近乎免费）

- 注册步骤：打开 platform.deepseek.com → 手机号注册 → 「API keys」→ 创建 → 复制。
- 新账户一般有赠送余额；充 10 元也够微信日常问答用很久。适合当其他几家都限流时的备胎。

## 你要做的全部操作（十分钟）

1. 把《给学员的 Agent-安装指令》这份文件发给你的 AI 助手，说：「按这份指令部署微信桥的快速通道。」
2. 它会让你在上面五家里选一家（不选默认智谱），并把注册步骤发给你。
3. 你按步骤注册、复制 API Key，发给它。它会自己填好接口地址和模型名——三项配置里，只有 Key 需要你出。
4. 它会自测三条消息并报告耗时，你照着下一节的标准验收就行。

## 验收标准（你的 Agent 应该报给你这三个数）

| 测试 | 达标线 |
|------|--------|
| 发一道没问过的常识题 | ≤5 秒收到完整回答 |
| 把同一道题再发一遍 | ≤3 秒（命中缓存） |
| 发一个复杂任务（如整理开支成表格） | 1 秒内先收到回执，且最终只有一份结果、不重复 |

任何一项不达标，让 Agent 按安装指令第五步的排查顺序自查，不要将就——慢的根源基本都在「轮询太慢、两个进程抢消息、连接没复用」这三处。

## 常见坑

- **Key 泄露**：Key 只发给你的 Agent、只存在你电脑的配置文件里；不要发群里、不要截图晒、不要传到公开仓库。用完怀疑泄露，去平台控制台删掉重建即可。
- **实名认证**：国内平台基本都要实名后才给免费额度，这是正常步骤，不是收费陷阱。
- **免费名单会变**：模型下线、额度调整都很常见。本章信息核实于 2026-11-04；调不通时先看控制台公告，换同平台的现行免费型号即可，配置里只改模型名一项。
- **高峰期限流**：免费档并发有限，偶尔慢一两秒属正常；连续失败先换备用平台，不要反复重试轰平台接口。
- **微信里只聊简单的**：快速通道只答通用常识；涉及你个人文件、日程、账号的问题会自动转主 Agent，稍慢是正常的，那是它在认真办事。
